# SQL题评分 Prompt

基于通用基础 prompt，这份文件补充 SQL 题的专项评分规则。

适用范围：
- SQL 查询题
- SQL 分析题
- 表连接题
- 聚合统计题
- 数据清洗/更新题

---

## SQL题专项补充

```text
对于 SQL 题，你必须重点检查以下内容：

1. 查询结果正确性
   - SQL 是否能得到符合题意的结果；
   - 是否因 JOIN、过滤条件、聚合条件、排序、分组等错误导致结果偏差。

2. 逻辑完整性
   - 是否完整覆盖题目要求的所有筛选、关联、聚合或输出字段；
   - 是否遗漏去重、NULL 处理、分组条件、排序条件等关键步骤。

3. SQL 可执行性
   - 是否存在语法错误、表字段引用错误、聚合使用错误；
   - 若无法执行，应明确指出不可执行原因。

4. 语义等价判断
   - 允许不同 SQL 写法但语义等价的实现得分；
   - 不因写法不同而误判。

5. 场景合理性
   - 是否考虑实际业务中的重复数据、NULL 值、边界数据、数据缺失等影响；
   - 如果题目要求面向场景，应检查 SQL 是否足够稳健。

6. 结果精确性
   - 是否多查、少查、错查；
   - 是否存在重复记录、关联范围错误、过滤条件不完整等问题。

输出时，你需要特别在：
- deduction_reasons 中写清 JOIN 类型、过滤条件、聚合逻辑、NULL/去重等问题；
- strengths 中概括正确使用的 SQL 技巧与思路；
- improvement_suggestions 中给出具体 SQL 层面的修正建议；
- evidence_summary 中概括命中的关键知识点、逻辑缺失点和执行/结果风险。
```

---

## 理想评分思路

1. 先明确题目要求输出什么结果。
2. 检查 SQL 是否完整覆盖查询条件、关联关系、分组和输出要求。
3. 判断是否存在执行错误、结果偏差或业务场景遗漏。
4. 接受语义等价的不同 SQL 写法。
5. 输出分项得分、扣分原因、优点、学习建议。
