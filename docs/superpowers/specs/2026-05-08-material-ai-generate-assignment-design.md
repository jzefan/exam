# Material AI Generate Assignment Design

**Goal**

在知识点的“根据上传资料进行 AI 出题”流程里，新增“生成作业”能力：用户基于当前已生成并勾选的题目，直接选择班级/学生，系统自动将题目保存到当前用户自己的“课程题库”，并以默认参数创建一份练习/作业。

## Scope

只覆盖知识点学习资料弹窗内的 AI 出题后续动作，不改造通用作业创建页的信息架构。用户不需要在这里设置开始时间、结束时间、时长、分数等通用考试参数。

## User Flow

1. 用户在知识点的“学习资料”弹窗中，点击“用此文件智能出题”。
2. `MaterialAIGenerateDialog` 生成题目，用户勾选要采用的题目。
3. 除“保存到课程题库”外，底部新增“生成作业”按钮。
4. 点击“生成作业”后，打开一个精简弹窗：
   - 可编辑作业名称
   - 选择班级 / 选择学生
   - 显示题目数量与默认发布规则说明
5. 用户点击“发布作业”。
6. 系统先将当前勾选题目保存到当前用户私有 `课程题库`，再用这些题目创建 `practice`。
7. 创建成功后，关闭精简作业弹窗；AI 出题弹窗可以保留或关闭，本次实现默认关闭并提示成功。

## Default Rules

创建作业时固定使用以下默认值：

- `category = "practice"`
- `start_time = now`
- `end_time = now + 14 days`
- `duration_minutes = 60`
- 不要求用户配置分数
- 题目来源为当前 AI 生成并勾选的题目
- 题目自动保存到当前用户自己的 `课程题库`

## Permissions

- 只能选择**当前教师名下的学生**。
- 选人方式与现有创建作业一致：支持按班级全选，也支持逐个学生勾选。
- 题目保存到**当前用户私有题库**，不写入公共题库。
- 发布作业仍遵循现有练习/作业创建权限，不为其他角色放宽权限。

## Frontend Design

### 1. `MaterialAIGenerateDialog.tsx`

新增按钮：
- `生成作业`

按钮启用条件：
- 当前不在生成中
- 当前不在保存中
- 至少勾选 1 道题

点击后打开新的精简发布弹窗，向其传入：
- 当前知识点名称 / 路径
- 当前勾选题目
- 当前用户可选的班级与学生数据源

### 2. 新增精简作业弹窗组件

建议新增独立组件，例如：
- `frontend/src/pages/knowledge/GeneratedAssignmentDialog.tsx`

职责：
- 展示作业名称输入框
- 复用现有班级/学生选择方式
- 展示“共 N 道题、立即开始、2 周后截止、时长 60 分钟”的说明
- 点击发布时调用保存与创建作业流程

### 3. 复用选人逻辑

不复制整页 `practice-create` 的所有字段和布局，而是抽取/复用其中的“学生选择”能力：
- 班级列表
- 班级全选学生
- 单独勾选学生
- 当前教师名下学生过滤

如果当前作业创建页的学生选择逻辑没有独立组件，则本次应抽成一个可复用组件，供：
- `practice-create.tsx`
- `GeneratedAssignmentDialog.tsx`

共同使用。

## Backend Design

### 1. 保存题目

继续复用已经新增的专用接口：
- `POST /api/questions/save-generated-to-course-bank`

输入为当前选中的生成题目。返回创建后的题目数量；如果当前返回值不足以拿到题目 ID，则需要增强该接口返回：
- `created_question_ids`

因为创建作业需要明确的题目 ID 列表。

### 2. 创建作业

复用现有 `practice` / `exam` 创建接口或服务层，只传入：
- 标题
- 说明（可空）
- `category = practice`
- `question_ids`
- `student_ids`
- `start_time = now`
- `end_time = now + 14 days`
- `duration_minutes = 60`

如果现有接口强制要求更多字段，本次应在服务层补默认值，避免前端被迫展示多余表单。

### 3. 学生范围

学生查询必须限定为当前教师名下学生。复用现有作业创建页使用的数据来源，不新增更宽权限的数据接口。

## State Updates After Success

发布作业成功后：
- 提示成功 toast，例如：`已发布作业《数字特征练习》给 32 名学生`
- 刷新相关题目列表（因为题目已保存）
- 关闭相关弹窗
- 可选：提供“查看作业”跳转入口（本次可不做）

## Error Handling

- 如果没有勾选题目，禁止发布。
- 如果未选择任何学生，禁止发布。
- 如果保存题目成功但创建作业失败，应给出明确错误提示；不回滚已保存题目，避免复杂事务扩散到跨域功能。
- 如果用户对某些学生或题目没有权限，沿用现有权限错误文案。

## Testing

### Frontend

- `MaterialAIGenerateDialog`：有勾选题目时显示并启用“生成作业”。
- `GeneratedAssignmentDialog`：
  - 班级全选 / 单独勾选学生逻辑正常
  - 未选学生时按钮禁用
  - 发布后调用保存题目接口与作业创建接口

### Backend

- 保存题目到课程题库后能返回可用于创建作业的题目标识
- 练习创建接口可接受默认时间参数与题目 ID
- 学生范围限制为当前教师名下

## Out of Scope

- 不新增考试模式配置
- 不在这个弹窗里配置成绩、总分、展示结果策略等复杂参数
- 不新增“查看作业详情”专用跳转页
- 不支持学生/非教师用户在此发布作业
