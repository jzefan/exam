# 书籍目录拍照导入知识库设计

## 目标

在知识库管理页 `/knowledge` 的右侧区域，增加与“导入知识库（Excel）”并列的第二个入口“书籍目录拍照导入”。

用户先选定一个方向，再上传图片或扫描版 PDF。系统通过 AI 识别书籍目录，抽取出层级路径，先给出预览，用户确认后再导入到当前方向的知识树中。

## 入口与交互

- 入口位置：知识库管理页右侧顶部操作区，与“导入知识库”并列。
- 按钮文案：`书籍目录拍照导入`
- 支持文件：
  - 图片：`jpg/png/jpeg/heic/webp`
  - 文档：`pdf`

## 流程

1. 用户在左侧选定方向
2. 点击 `书籍目录拍照导入`
3. 打开上传弹窗
4. 上传图片或扫描版 PDF
5. 后端调用多模态模型识别目录结构
6. 前端展示“目录识别预览”
7. 用户确认后导入
8. 系统将目录路径逐层写入当前方向知识树
9. 已有节点复用，缺失节点补建

## 预览内容

- 文件名
- 识别出的目录路径总数
- 最大层级
- 一级目录数量
- 前 20-30 条目录路径预览
- 错误提示区

预览阶段不直接写库。

## 识别输出结构

后端返回统一路径结构：

```json
{
  "paths": [
    ["第1章 数据库系统概述", "1.1 数据模型", "1.1.1 关系模型"],
    ["第1章 数据库系统概述", "1.2 数据独立性"]
  ]
}
```

## 识别规则

- 优先识别常见目录编号：
  - `第1章`
  - `第1节`
  - `1.`
  - `1.1`
  - `1.1.1`
  - `一、`
  - `（一）`
- 若无明显编号，则基于文本顺序和版面层级推断
- 输出必须为 JSON，不返回解释性文字
- 拍照和 PDF 识别都走同一条 AI 目录识别链路

## 导入规则

- 必须在已选方向下导入
- 同一方向内：
  - 同名且同父节点的知识点视为已存在，直接复用
  - 缺失节点自动补建
- 导入成功后刷新当前方向知识树
- 成功提示新增数量

## 错误处理

- 未选择方向：阻止打开或阻止提交，并提示“请先选择方向”
- 文件不支持：提示支持的格式
- AI 识别失败：提示“目录识别失败，请重试”
- AI 返回结构异常：提示“目录结构解析失败，请重试”
- 无可识别目录：提示“没有识别到可导入的目录结构”

## 实现范围

本轮实现：

- 前端新增拍照导入入口和预览弹窗
- 后端新增目录识别接口
- 使用现有知识点创建逻辑导入目录路径

本轮不实现：

- 浏览器摄像头直接拍照
- OCR 引擎本地化
- 目录识别结果的树形拖拽编辑
