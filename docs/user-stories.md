## US-QB-01 手动创建题目 🔴

### 用户角色
**作为** 教师/管理员

### 功能需求
**我想要** 手动创建各类题目（选择、判断、填空、简答、论述、代码题），输入题目内容、选项、标准答案、解析、难度、分值、标签

### 业务价值
**以便于** 建立结构化题库，为考试组卷和 AI 评分提供基础数据

### 验收标准
- [ ] 支持 6 种题型：选择（单选/多选）、判断、填空、简答、论述、代码
- [ ] 题目内容支持富文本（文本、图片、代码块）
- [ ] 选择题支持设置多个选项和正确答案
- [ ] 必须填写：题型、标题、内容、答案、难度（1-5）、分值
- [ ] 可选填写：解析、标签、所属题库
- [ ] 创建成功后题目出现在题目列表中

### 详细描述
- 选择题 answer 结构：`{correct: "A"}` 或 `{correct: ["A","B"]}`
- 判断题 answer：`{correct: true/false}`
- 填空题 answer：`{blanks: ["答案1", "答案2"]}`
- 简答/论述/代码题 answer：`{points: ["要点1", "要点2"]}`
- 每道题必须关联一个创建人（当前登录用户）

### 依赖与关联
- 前置条件：用户已登录且角色为教师或管理员
- 关联功能：标签管理、题库管理、知识点管理

## US-QB-02 文件导入题目 🔴

### 用户角色
**作为** 教师/管理员

### 功能需求
**我想要** 通过上传 Word、PDF、Excel、TXT 文件批量导入题目，系统自动识别题型、内容和答案

### 业务价值
**以便于** 快速将已有试卷或题库迁移到系统中，减少手动录入工作量

### 验收标准
- [ ] 支持 .docx、.pdf、.xlsx、.txt 格式上传
- [ ] 系统调用 AI 自动识别题目结构（题型、题干、选项、答案）
- [ ] 识别结果展示给用户进行确认和修改
- [ ] 支持批量确认创建
- [ ] 识别失败的题目高亮提示，可手动修正

### 详细描述
- 文件解析流程：上传 → 文本提取 → AI 分析（题型识别、结构化拆分）→ 预览确认 → 批量入库
- OCR 功能：图片/扫描 PDF 支持 OCR 识别
- AI 语义修复：对 OCR 识别出的乱码进行上下文纠错

### 依赖与关联
- 前置条件：文件上传服务可用
- 外部依赖：OCR 服务、AI 模型接口

**以便于** 组织一场完整的在线考试

## US-GR-01 多模型协同自动评分 🔴

### 用户角色
**作为** 系统

### 功能需求
**我想要** 对学生提交的主观题答案进行多模型协同自动评分

### 业务价值
**以便于** 高效、公正地评阅大量主观题，减少人工阅卷工作量

### 验收标准
- [ ] 支持三种模型角色：评分老师（初评）、评分审核（复评）、最终评判（仲裁）
- [ ] 默认配置：Qwen→初评，DeepSeek→复评，Claude/Gemini→终审
- [ ] 双模型评分分差超过 15% 时自动触发第三模型仲裁
- [ ] 每次评分返回：各维度评分、综合评分、扣分原因、优点分析、改进建议
- [ ] 评分响应时间 < 5 秒

### 详细描述
- 代码题评分维度：功能正确性、代码可读性、语法正确性、算法效率、异常处理、代码规范
- 简答题评分维度：知识点覆盖、逻辑结构、准确性、完整性、表达能力
- 开放性问题评分维度：思维深度、逻辑性、创新性、论证能力
- 代码题增加沙箱运行验证，单元测试结果作为 AI 评分输入

### 非功能性需求
- 性能要求：单题评分 < 5 秒
- 安全要求：代码沙箱隔离运行

### 依赖与关联
- 外部依赖：Qwen API、DeepSeek API、Claude API、Gemini API
- 关联功能：US-EX-01 考试系统
