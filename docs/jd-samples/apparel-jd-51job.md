## 岗位信息

- 岗位名称：服装设计师
- 产业方向：服装 / 纺织 / 服饰设计
- 学历参考：大专及以上
- 适合专业：纺织工程、服装与服饰设计等相关专业

## 职位描述整理

### 岗位职责

1. 收集和分析服装流行趋势、流行色、面辅料、搭配方式等行业信息。
2. 根据品牌定位、市场需求或客户需求，参与服装产品开发与款式设计。
3. 绘制服装设计效果图、款式图，形成设计方案。
4. 针对具体款式提出面料、辅料、色彩、工艺和搭配建议。
5. 跟进样衣打样过程，关注版型、工艺、质量和开发进度。
6. 根据样衣反馈调整设计方案，完善产品细节。
7. 配合产品订货、上新、营销等环节，为新品开发提供支持。

### 涉及技术与工具

- Photoshop
- Illustrator
- 服装款式图绘制
- 服装效果图表达
- 面辅料识别与应用
- 流行趋势分析
- 样衣打样与版型沟通

### 任职要求

1. 具备服装设计、服装与服饰设计、纺织工程等相关专业基础。
2. 理解服装产品开发流程，能从趋势、款式、面辅料和工艺角度进行设计表达。
3. 熟悉 Photoshop、Illustrator 等常用设计工具。
4. 对服装流行趋势、色彩、面辅料和市场需求有较好的敏感度。
5. 具备沟通协作能力，能够与版师、样衣、生产、商品等相关岗位协同工作。

## 可提炼的岗位能力项

- 服装流行趋势分析
- 服装款式设计与视觉表达
- 面辅料认知与搭配应用
- 样衣开发与版型沟通
- 服装产品开发流程理解
- 设计软件应用能力
- 市场需求转化能力
