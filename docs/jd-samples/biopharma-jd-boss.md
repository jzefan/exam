## 岗位信息

- 岗位名称：研发项目经理
- 产业方向：生物医药 / 生物制药 / 体外诊断
- 典型工作场景：诊断试剂研发、产品转化、注册申报、研发项目管理
- 学历参考：本科、硕士及以上，部分企业要求博士

## 职位描述整理

### 岗位职责

1. 负责生物医药或体外诊断相关产品的研发项目管理。
2. 参与项目立项、可行性调研、技术路线设计和项目计划制定。
3. 组织或推进试剂盒、检测产品、分子诊断产品等研发工作。
4. 负责实验方案设计、实验过程跟进、产品性能评价和工艺优化。
5. 协调研发、生产、质量、注册、临床等相关部门，推动项目按计划转产或上线。
6. 编写或审核项目计划书、技术文档、实验记录、注册申报资料等文件。
7. 参与产品注册、临床试验、生产转化、上市后技术支持等工作。
8. 负责研发团队成员培养、任务分配、进度汇报和跨部门沟通。

### 涉及技术与领域

- 生物工程
- 基因工程
- 分子生物学
- 免疫学
- 医学检验
- PCR
- 体外诊断试剂
- 化学发光检测
- 临床试验
- 产品注册申报
- 研发项目管理

### 任职要求

1. 具备生物学、医学、免疫学、分子生物学、临床医学、医学检验等相关专业背景。
2. 熟悉体外诊断、生物制药或相关检测产品的研发流程。
3. 具备实验方案设计、实验执行、数据分析和问题解决能力。
4. 熟悉产品开发、工艺优化、性能评价、生产转化和注册申报等关键环节。
5. 具有较强的文献检索、技术资料整理和技术文档撰写能力。
6. 具备项目管理、进度控制、资源协调和团队沟通能力。
7. 有成功注册报批、临床实验、试剂研发或产品上市经验者优先。
